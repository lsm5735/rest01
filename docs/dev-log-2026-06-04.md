## 4. 히어로 영역 JavaScript 효과

| 효과 | 구현 방식 |
|------|-----------|
| 파티클 배경 | `<canvas>` + `requestAnimationFrame` 루프, 55개 파티클 + 연결선 |
| 순차 페이드인 | 사진 → 인사말 → 이름 → 직함 → 소개 → 연락처, 150ms 간격 |
| 타이핑 효과 | 직함 텍스트를 55ms/글자 속도로 타이핑, 커서 깜빡임 애니메이션 |
| 스크롤 페이드인 | `IntersectionObserver`로 각 섹션 뷰포트 진입 시 슬라이드업 |

## 9. 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| GitHub Pages 404 | Actions 탭에 워크플로 없음, branch 설정 미저장 | `gh-pages` orphan 브랜치 생성 후 직접 push |
| workflow 파일 push 실패 | GitHub Token에 `workflow` scope 없음 | Actions 방식 포기 → branch deploy 방식 유지 |
| 히어로 배경이 파란색 유지 | `color-mix()` CSS 함수 실패 시 팔레트 blue가 우선 적용 | `color-mix()` 제거, 하드코딩 그라디언트로 교체 |
| 변경사항이 반영 안 됨 | 브라우저·CDN이 구 버전 CSS를 캐시 | `style.css?v=3` 버전 쿼리 추가로 강제 갱신 |
