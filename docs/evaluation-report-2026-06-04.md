## 4. 트러블슈팅 이력 및 학습 사항

### 4-1. GitHub Pages 배포 이슈
- **문제**: `gh` CLI 미설치, GitHub Token `workflow` scope 없음
- **결론**: Actions 워크플로 없이 `gh-pages` orphan 브랜치로 수동 배포
- **학습**: GitHub Token 권한 범위에 따라 배포 방식 선택 필요

### 4-2. CSS `color-mix()` 호환성 이슈
- **문제**: 히어로 배경에 `color-mix()` 사용 → 일부 환경에서 파싱 실패 → 파란 팔레트 색상이 노출
- **결론**: 하드코딩 그라디언트(`#111827 → #374151 → #4a2c14`)로 교체
- **학습**: `color-mix()`는 Chrome 111+, Safari 16.2+ 이상만 지원. 폴백 필수

### 4-3. 브라우저·CDN 캐시 이슈
- **문제**: CSS 업데이트 후에도 브라우저가 구 버전 파일 캐시
- **결론**: `style.css?v=3` 버전 쿼리 추가로 강제 갱신
- **학습**: 정적 사이트 배포 시 캐시 버스팅 전략 사전 설계 필요

## 5. 개선 권고 사항

### 단기 (즉시 적용 가능)
1. **WebP 이미지 변환** — `profile.png`, `og-image.png` WebP로 변환하면 파일 크기 40~60% 절감

3. **카카오 OG 캐시 초기화** — 공유 전 [카카오 개발자 OG 초기화 도구](https://developers.kakao.com/tool/clear/og) 실행

### 중기 (기능 확장)
4. **인쇄/PDF 스타일** — `@media print` 추가로 PDF 출력 지원
5. **언어 전환** — 한국어/영어 토글 (data.js에 lang 키 추가)
6. **연락처 폼** — Formspree 등 서드파티 활용한 이메일 수신 폼

### 장기 (구조 개선)
7. **자동 캐시 버스팅** — Vite 등 번들러 도입 시 파일 해시 자동화
8. **GitHub Actions 자동 배포** — Token에 `workflow` scope 추가 후 CI/CD 파이프라인 구성
